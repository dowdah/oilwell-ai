# 8～10 分钟课程演示提纲

适用课程：《石化信息工程》。本提纲与 [完整使用说明](user-guide-and-demo.md) 配套；页面操作以完整说明为准。

## 演示前准备

- 打开 [演示系统](https://oil-well-ai-demo.dowdah.com/)，确认设备在线、两个模型 ready。
- 进入“边缘与回放”，先确认已有回放停止，加载已彩排的文件，再设置 10×并等待设备回执。设备重启后实例可能为空，不能直接点击开始。
- 2026-10-17 只读复查时设备为 ONLINE、20×、未加载实例；这是检查时的状态，不是系统默认值。
- 若展示实时推理，提前送入完整 180 秒数据窗口。若只展示已保存报告，无需启动回放。
- 准备截图或录像，断网时明确说明使用历史材料。查看报告不额外调用 LLM，生成新报告可能收费。

## 讲解边界

- 检索是受审阅静态条目的关键词匹配；外部 LLM 收到的是引用元数据而非知识文档全文。
- XGBoost/TCN 做窗口分类，DeepSeek 组织辅助分析；References 由系统生成，模型文本仍需人工核验。
- 被否决的二分类候选与当前运行的四分类模型不同，不可混为一谈。
- 系统不执行现场控制；完整数据与模型制品不随 Git 源码包提供，见 [交付清单](delivery-manifest.md)。
