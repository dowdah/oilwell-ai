## 3. 模型研究结论：二分类候选 rejected

**Candidate status: rejected；deployment status: never deployed。** 唯一候选为沿用四源标签 class weighting 的 binary XGBoost，没有新增特征、网络、数据扩展或参数搜索。验证集最大化 abnormal F1 的阈值为 `0.0618476532`。

| 集合 | Abnormal Precision | Abnormal Recall | Abnormal F1 | False positive rate |
| --- | ---: | ---: | ---: | ---: |
| Validation | 0.9435 | 1.0000 | 0.9710 | 0.0240 |
| Held-out WELL-00014 | 1.0000 | 0.0249 | 0.0485 | 0.0000 |

测试混淆矩阵为 `[[4923, 0], [22598, 576]]`（行是真实 Normal/Abnormal，列是预测）；Macro F1 `0.1760`，ROC-AUC `0.4574`，PR-AUC `0.8339`。异常召回率约 **2.49%**、异常 F1 约 **4.85%**，验证高分没有泛化至独立井。PR-AUC 在异常占多数的测试井上也不能证明选定阈值可用。

验证集没有 class 3，测试仅有 WELL-00014，因此不能声称各异常类别稳定跨井泛化。该结论针对当时数据、冻结协议和唯一候选，不能扩展为未取得数据的实验结果。候选被否决后没有训练候选 2/3，也没有重用测试集调参。

旧二分类模型 SHA-256 为 `fd3a5e4014714b52d4bd87e71add404970e3f36befb317188918d11062edc590`，仅作为历史标识保留；该被否决模型不在本次交付资产白名单内。当前运行的是四分类 XGBoost active 与 TCN shadow，两者与被否决候选不是同一模型。保留的九个制品见 [演示资产清单](../experiments/demo-assets.json)，新训练模型不能直接替换当前制品。

## 4. 能力限制与验收方法

- **教学边界**：数据由公开 3W 文件回放，未接入实体油井传感器；系统不执行现场控制，模型输出为 `Experimental model output`，不构成工业诊断或生产决策。
- **泛化边界**：窗口分类、工程链路可运行不等于异常识别可靠；置信度不是准确率，未做新一轮四类全量准确率、跨井泛化或长期稳定性验证。
- **LLM 边界**：外部输入为井和窗口标识、七变量统计、模型结果、报警摘要及引用元数据，不含完整原始时序或知识文档全文。模型文字仍需人工核验；References 由系统从本次检索集合生成。
- **降级边界**：LLM 不可用或格式错误时保留模板并标记 `LLM analysis unavailable`；缺少同窗口 SHAP 时，即使调用成功也保留证据降级。证据不足时可拒答。
- **数据统计边界**：同一文件多次回放按不同接收序列保存；诊断按井和采样时间取数，未按回放批次隔离，样本数可能超过单窗口采样数。
- **检索与费用**：只提供受审阅静态清单的关键词检索，没有文档上传、embedding 或向量库。单次输出有限额，但没有全站每日费用上限；公开入口的访问控制、限流和供应商预算需按使用范围管理。
- **部署边界**：源码 ZIP 不含数据、模型、凭据或依赖；目标 API 为 Linux amd64 / Python 3.12。新机器完整部署和数据库恢复演练未在本轮重做，生产健康与历史报告可读不能替代新请求验证。

独立环境验收应依次检查：模型 ready、设备心跳、命令回执、新遥测入库、WebSocket 更新、完整 active/shadow 窗口、真实连续窗口报警条件、诊断引用与降级/拒答。真实 LLM 联调需数据使用授权及费用预算；MQTT 断连、重启或备份恢复测试只在隔离环境或获准维护窗口进行。

课程现场以 [使用与演示方法](user-guide-and-demo.md) 为操作入口；无需为了展示而重跑训练或故障演练。
